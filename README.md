# SigmaGPT 🤖

SigmaGPT is an AI-powered chat application inspired by modern AI assistants like ChatGPT.

## 🚀 Features

- 💬 AI-powered conversations
- 🧵 Multiple chat threads
- 📜 Chat history
- 🤖 AI responses using OpenRouter
- 🗄️ MongoDB database integration
- ⚛️ React frontend
- 🟢 Node.js + Express backend

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- OpenRouter API
